# v3.0 Roadmap

v3.0 closes the remaining delta between the complete 60-metric catalog and the
live implementation.

## Feature Workstreams

1. Production validation automation
2. Collector Framework 2.0
3. Golden Config adapter
4. SSoT adapter
5. Device Lifecycle Management adapter
6. User activity collector
7. ROI baseline governance
8. Forecasting and thresholds
9. Retention rollups and archive
10. Reporting and export
11. Project wiki deployment and governance

## Final Major Revision Policy

v3.0 is treated as the final planned major feature expansion. Later releases
should prioritize:

- Bug fixes
- Security updates
- Nautobot compatibility
- Performance tuning
- Documentation refinement
- Optional adapter maintenance

New post-v3 features require explicit roadmap approval and should not expand
the project scope by default.
