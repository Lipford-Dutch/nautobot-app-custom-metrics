# Project Overview

Lipford Nautobot Metrics is a Nautobot 3.1 app for tracking automation ROI,
user activity, optional app metrics, lifecycle metrics, and Job metrics inside
Nautobot.

## Live Capabilities

- 60 canonical metric definitions
- Persistent metric observations
- Nautobot UI and dashboard
- REST API and summary endpoint
- GraphQL type registration
- Atomic authenticated ingestion endpoint
- Sample metric data Job
- JobResult and ObjectChange reference collectors
- Retention Job with dry-run support
- Release workflow with wheel, sdist, checksums, and provenance

## v3.0 Direction

v3.0 is the final planned major feature revision for completing the full
collector and operational roadmap. After v3.0, the project should move into
stability, bug-fix, security, compatibility, and integration-hardening releases.
