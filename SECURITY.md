# Security Policy

## Supported Versions

This project is currently in alpha. Security fixes are prioritized for the active development branch and the latest published release.

| Version | Supported |
| --- | --- |
| `0.1.x` | Yes |
| `<0.1.0` | No |

## Reporting a Vulnerability

Report suspected vulnerabilities through GitHub private vulnerability reporting when it is enabled for this repository. If private reporting is not enabled, open a GitHub issue with only high-level impact details and avoid posting exploit steps, credentials, tokens, customer data, or sensitive system information.

Include the following details when possible:

- Affected version or commit SHA.
- Nautobot, Python, and database versions.
- Deployment type.
- Impacted model, view, job, or API endpoint.
- Minimal reproduction steps that do not expose sensitive data.

## Handling Expectations

Security reports should be acknowledged by the repository maintainers before public disclosure. Fixes should include regression tests where practical and release notes under `docs/admin/release_notes/`.
